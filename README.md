# Dhanasarathy P — Portfolio

A responsive portfolio website generated from the supplied resume and styled as a clean, editorial CSE portfolio.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive design and animations
- `script.js` — mobile navigation and scroll reveal
- `resume.pdf` — supplied resume for the Download Resume button

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to Netlify
Upload the folder to Netlify Drop, or connect the folder/repository through Netlify.
